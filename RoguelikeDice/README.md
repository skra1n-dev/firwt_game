# RoguelikeDice — прототип 2D-игры «всё решает рандом» (Godot 4)

Мини-игра в духе DnD: вы появляетесь в подземелье, сражаетесь со случайными врагами,
получаете опыт, золото и прокачиваете оружие/броню. Каждый шаг определяется броском кубика.

## Как запустить
1. Установите [Godot 4.3+](https://godotengine.org/download) (бесплатно).
2. Откройте Godot → «Import» → выберите файл `project.godot` из этой папки.
3. Нажмите ▶ Play (F5). Играть можно мышкой — кнопки: Исследовать / Атаковать / Защититься / Отступить.

## Структура проекта
```
RoguelikeDice/
├── project.godot          # настройки движка
├── scenes/main.tscn       # главная сцена (пустой Control + скрипт)
├── scripts/
│   ├── main.gd            # вся игровая логика: состояния, бой, броски d20, лавка, UI
│   ├── player.gd          # характеристики игрока, уворот, атака, опыт, база предметов
│   ├── enemy.gd           # генерация случайных врагов
│   ├── weapon.gd          # Resource оружия: диапазон урона + крит
│   └── armor.gd           # Resource брони: диапазон блока
└── tests/test_run.gd      # автотест механик (запуск см. ниже)
```

## Как работают ваши механики (и где их крутить)

| Ваша идея | Реализация | Где менять |
|---|---|---|
| Урон оружия = случайное число из порога (10–20) | `randi_range(dmg_min, dmg_max)` | `weapon.gd` |
| Блок брони = число × фиксированный множитель | сделано как диапазон блока `randi_range(block_min, block_max)`; в действии «Защититься» блок умножается на 2 (фикс. множитель) | `armor.gd`, `main.gd:_on_defend` |
| Уворот = ловкость × фиксированное число | `agility * DODGE_COEF` (0.03), кап 60% | `player.gd` (константы сверху) |
| Каждое действие = бросок кубика | бросок d20: 20 = крит ×2 урона, 1 = провал (ход потерян), попадание = d20 + ловкость/2 против уклонения врага | `main.gd: roll_d20, _on_attack` |
| Прокачка оружия/снаряжения | лут с врагов (шанс 35%) + лавка после боёв, цены растут с глубиной | `main.gd:_on_victory`, `_on_buy_*` |

## Идеи для развития
- **Настоящий 2D-вид вместо кнопок**: Node2D + спрайты героя и врага, `AnimatedSprite2D`, камера. Логика боя уже изолирована — её можно переиспользовать.
- **Генерация карты**: тайловая `TileMapLayer` + случайные комнаты, «Исследовать» превратится в ходьбу.
- **Классы персонажа** (воин/маг/вор) — разные стартовые статы и коэффициенты.
- **Заклинания и статусы** (отравление = урон каждый ход по броску).
- **Сид-рандом** как в Hades/Vampire Survivors: `RandomNumberGenerator` с seed, чтобы «рандом» был воспроизводимым.
- Сохранение рекордов глубины в `FileAccess`.

Прототип проверен: весь код компилируется и запускается в Godot 4.3 без ошибок.
